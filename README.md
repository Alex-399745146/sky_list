# SKY_LIST

---

## Курсовая работа 

По итогам обучения 4-го модуля ООП

---

В этом проекте реализована интеграция с внешними сервисами:

* [API nominatim openstreetmap](https://nominatim.openstreetmap.org/ui/search.html)
* [API opensky network](https://opensky-network.org/)

## Описание проекта

программы с терминальным меню, которая будет собирать данные о самолетах в воздушных пространствах тех
стран, которые вы выберете.

---

## Стэк технологий:

```commandline
# magick_method #request #API #pandas #структура ООП(абстракт классы, миксины, множественное наследование, исключения)
```

## API key
Сервисные площадки куда интегрированна программа используют так называемый открытый API,
следовательно, ключи не нужны что только юзерфредли.
